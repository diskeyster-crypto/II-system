# DevBridge

> **Admin-only AI Development Management System**

DevBridge is a PHP 8.1+ web application that helps an operator manage AI-assisted software development through GPT, GitHub, and coding agents such as GitHub Copilot.

## What It Does

1. Operator discusses a task with GPT
2. GPT clarifies requirements and generates a Final Task Spec
3. Operator approves → DevBridge creates a GitHub Issue
4. Coding agent writes code and opens a Pull Request
5. DevBridge fetches the diff and triggers GPT code review
6. GPT reviews the code; if issues found → posts fix instructions to PR
7. If GPT cannot decide → sends task to Operator Decisions
8. If code is good → marks task **Ready for Manual Merge**

**No auto-merge. No auto-deploy. The human operator always makes the final decision.**

---

## Requirements

- PHP 8.1+
- MySQL 5.7+ / MariaDB 10.3+
- PHP extensions: `pdo`, `pdo_mysql`, `curl`, `json`, `mbstring`, `openssl`
- Web server (Apache/Nginx) with HTTPS recommended

---

## Installation

1. Upload the `devbridge/` folder to your web server
2. Open `https://yourdomain.com/devbridge/install.php` in your browser
3. Fill in the database credentials and admin account
4. Click **Install DevBridge**
5. The installer will:
   - Create the database and tables
   - Create the first admin user
   - Write `config/config.php`
   - Create `storage/` directories
   - Lock itself (`storage/installed.lock`)
6. Log in at `https://yourdomain.com/devbridge/login.php`

---

## Configuration

After installation, go to **Settings** in the admin panel and configure:

| Setting | Description |
|---|---|
| OpenRouter API Key | Your OpenRouter secret key (stored encrypted) |
| OpenRouter Model | Default AI model (`openai/gpt-4o`, etc.) |
| AI Temperature | 0.0–1.0, default 0.2 |
| Max Prompt Chars | Max characters sent to AI per request |
| GitHub Token | Personal access token with `repo` scope (stored encrypted) |
| Default GitHub Owner | Your GitHub user or org name |
| Webhook Base URL | Full URL to devbridge root (for GitHub webhooks) |

## Security

- CSRF tokens on all POST forms
- GitHub webhook HMAC-SHA256 signature validation
- API keys stored AES-256-GCM encrypted in database
- Secrets never displayed in full in the UI
- All SQL through PDO prepared statements
- All output escaped with `htmlspecialchars`
- `storage/` and `app/` blocked from direct browser access
- No `shell_exec`, `exec`, or `eval`
- No auto-merge, no auto-deploy

## AI Provider

DevBridge uses **OpenRouter** as the default AI provider (OpenAI-compatible API).
Any OpenAI-compatible API can be used by modifying `app/AI/OpenRouterClient.php`.

## Workflow

### Creating a Task

1. Go to **Dev Tasks → New Task**
2. Select project and repository
3. Enter title and initial request
4. Click **Create & Open Chat**
5. Discuss with GPT until it generates the **Final Task Spec**
6. Review and optionally edit the spec
7. Click **Approve & Create Issue** to create the GitHub Issue

### After a PR is Opened

1. GitHub webhook triggers → PR data stored in task
2. Go to the task and click **Fetch PR Diff**
3. Click **GPT Review** to start the code review
4. GPT returns a structured JSON review
5. If changes needed → comment is automatically posted to PR
6. After up to 3 fix cycles → operator makes the final call
7. If approved → task marked as **Ready for Manual Merge**

### Roadmap Management

- Each repository can have a living roadmap (`ROADMAP.md` + `.devbridge/` folder)
- GPT can propose roadmap changes (pending operator approval)
- See **Roadmaps** section to approve/reject/apply proposals
